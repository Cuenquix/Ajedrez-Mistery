# Ajedrez Mistery

**Ajedrez Mistery** es una variante original de ajedrez creada por **Marc Cuenca Sastre (Cuenquix)**. Este repositorio contiene el juego web y su portal público.

## Jugar
https://cuenquix.github.io/Ajedrez-Mistery/

Juego directo:
https://cuenquix.github.io/Ajedrez-Mistery/juegos/ajedrez-mistery.html

## Proyecto
El proyecto se centra en Ajedrez Mistery: preparación personalizada de la posición inicial, partidas contra bots y modo local para dos jugadores. Los modos de rival online actualmente son simulados; todavía no hay multijugador en tiempo real con servidor.

## Estructura
- `index.html` — portal de Ajedrez Mistery.
- `juegos/ajedrez-mistery.html` — juego.
- `academia.html` — academia, 100 preguntas y reto diario.
- `tablero.html` — retos tácticos interactivos sobre tablero.
- `manifest.webmanifest` y `sw.js` — instalación como web app y caché.
- `icons/` — iconos de la aplicación.

## Instalación
Se puede abrir y jugar directamente desde el navegador. En navegadores compatibles, también puede añadirse a la pantalla de inicio. No es una aplicación nativa publicada en las tiendas.

## Publicación
Publicado con GitHub Pages desde la rama `main`. El repositorio conserva su nombre para mantener la dirección pública.
