# Ajedrez Mistery — Cuenquix

Web estática del proyecto Ajedrez Mistery, preparada para GitHub Pages.

## Estructura
- `index.html`: portada principal.
- `juegos/ajedrez-mistery.html`: juego Ajedrez Mistery Pro.

## Activar GitHub Pages
1. Abre **Settings → Pages** en este repositorio.
2. En **Build and deployment**, selecciona **Deploy from a branch**.
3. Elige la rama `main` y la carpeta `/(root)`.
4. Guarda y espera a que finalice la publicación.

La URL será `https://cuenquix.github.io/Ajedrez-Mistery/`.

## Notas
El juego funciona como web estática, sin servidor ni instalación. Las estadísticas se guardan localmente en el navegador y no se sincronizan entre dispositivos. Los modos de rival simulado/IA no son multijugador online real.
